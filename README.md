# jev-milkboy

ミルクボーイのコーンフレーク漫才で、駒場がおかんの好きな朝ごはんの特徴を説明するセリフ1つ1つについて、TypeSafe AI の **Jev** にコーンフレークのことかどうかを判定させ、内海として「コーンフレークやないかい」または「ほなコーンフレークと違うかぁ」と返すプログラムです。

- 各セリフを `state`（テキスト）として、「このセリフの特徴はコーンフレークに当てはまるか？」という yes/no 質問（`Noul`）と一緒に Jev に渡します。
- Jev が返す yes の確率が `--threshold`（既定 0.5）以上なら「コーンフレークやないかい」、未満なら「ほなコーンフレークと違うかぁ」と返します。
- 既定のモデルは `jev-latest` です。`--model` で変更できます。

## セットアップ

[mise](https://mise.jdx.dev/) で Python と [uv](https://docs.astral.sh/uv/) を用意し、uv で依存関係をインストールします。

```sh
mise install                  # mise.toml の指定どおりに Python と uv をインストール
uv sync --extra test          # uv.lock のとおりに .venv へインストール
cp .env.example .env          # .env に TypeSafe AI の API キーを書く
```

`.env` の `TYPESAFE_API_KEY` に API キーを書いておくと起動時に読み込まれます。環境変数が設定されていればそちらが優先されます。

## セリフの用意

`lines.txt` には、[note の記事](https://note.com/mochicosan/n/nf1e3397cb7e5)から、駒場がおかんの好きな朝ごはんの特徴を説明するセリフを1行に1つずつ収めています。

- 空行と `#` で始まる行は無視されます。
- 書式は `lines.example.txt` を参考にしてください（中のセリフは自作の例で、実際の台本ではありません）。

## 使い方

```sh
uv run jev-milkboy lines.txt                  # ファイルから読み込む
cat lines.txt | uv run jev-milkboy            # 標準入力から読み込む
uv run jev-milkboy lines.txt --threshold 0.7  # より自信があるときだけコーンフレークと判定する
```

出力例:

```
駒場: 甘くてサクサクしてて、牛乳をかけて食べるらしいねん
内海: コーンフレークやないかい (yes 0.97)

駒場: 炊きたてを茶碗によそって、お箸で食べるらしいねん
内海: ほなコーンフレークと違うかぁ (yes 0.02)

判定: 2/2  コーンフレークやないかい: 1  ほなコーンフレークと違うかぁ: 1  エラー: 0  モデル: ...  入力トークン: ...
```

（上の確率は説明用の例です。）出力は入力の順番どおりです。API エラーになったセリフは `(判定失敗: ...)` と表示し、処理は止めずに続けます。

| オプション | 既定値 | 説明 |
|---|---|---|
| `file` | `-`（標準入力） | 1行1セリフのテキストファイル |
| `--model` | `jev-latest` | 使用するモデル |
| `--threshold` | 0.5 | 「コーンフレークやないかい」と判定する yes 確率の下限 |
| `--concurrency` | 8 | 同時リクエスト数 |
| `--timeout` | 60 | リクエストごとのタイムアウト（秒） |

## テスト

```sh
uv run pytest
```

API キーやネットワーク接続なしで動くオフラインテストです。
